# A docs/README.md lista mindig naprakész

Ha a `./docs` mappában dolgozol, és új dokumentációt hozol létre, vedd fel azt a `C:\Projects\test\docs\README.md` fájl listájába is.

- Minden új `docs/*.md` fájlhoz tartozzon egy sor a README-ben: `- [Cím](fajlnev.md)`.
- A link címe egyezzen a dokumentum `#` főcímével, a hivatkozás pedig a README-hez viszonyított relatív útvonal legyen.
- Ha dokumentációt átnevezel vagy törölsz, a README-ben is javítsd vagy töröld a hozzá tartozó sort.
- A munka végén ellenőrizd, hogy a `docs` mappa minden dokumentuma szerepel a listában (a `README.md` kivételével), és minden listaelem létező fájlra mutat.
